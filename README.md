# Tripleten web_project_around_es

## 📖 Project Description

**Around The U.S.** is an interactive web application developed as part of my Full Stack Web Development training at TripleTen.

The main purpose of this project was to apply and strengthen the knowledge acquired throughout the bootcamp by building a dynamic user interface that allows users to view, create, and manage content through interactive cards.

This project demonstrates key Front-End development concepts, including DOM manipulation, event handling, form validation, and responsive web design.

---

## 🎯 Learning Objectives

Throughout this project, I practiced and reinforced skills related to:

- Semantic HTML5 structure.
- Responsive design using CSS3.
- Styling organization following the BEM methodology.
- Dynamic DOM manipulation using JavaScript.
- Creation and management of reusable components.
- User event handling.
- Real-time form validation.
- HTML templates for dynamic content generation.
- Modal (Popup) implementation.
- Version control with Git and GitHub.

## ✨ Features

### User Profile

- Edit profile name and description.
- Dynamic profile updates displayed on the page.

### Card Management

- Display predefined cards.
- Create new cards through a form.
- Delete existing cards.
- Interactive like functionality.

### Image Gallery

- Image preview through modal windows.
- Display image titles and descriptions.

### User Experience

- Modal closing functionality through:
  - Close button.
  - ESC key.
  - Overlay click.

- Real-time form validation.
- Automatic button enable/disable behavior based on form validity.

### Responsive Design

The application was built to provide a consistent experience across multiple screen sizes:

- Desktop
- Tablet
- Mobile

---

## 🔍 Technical Challenges

One of the main challenges during this project was implementing reusable card components using HTML templates and JavaScript DOM manipulation while keeping the code organized, scalable, and maintainable.

Another challenge was building a form validation system that improved the user experience by dynamically enabling and disabling action buttons based on input validity.
